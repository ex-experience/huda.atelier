# ATELIER HUDA — Editorial Edition

Rebuilt as a portfolio-first editorial website inspired by the interaction model of high-fashion artist portfolio sites: white canvas, minimal typography, dense media archive, mixed still/motion, hover captions, full-screen lightbox and unobtrusive commercial modules.

## Pages
- `index.html` — portfolio / motion archive
- `services.html` — private services and Atelier methods
- `shop.html` — THE EDIT, reference pricing, pre-order cart, 10% service privilege proposal
- `academy.html` — individual, pro and institutional training
- `digital.html` — digital books, templates and video products
- `concierge.html` — structured request → WhatsApp draft

## Brand features integrated
Hijazi Light™, 90-Day Bridal Protocol, Look DNA, Silent Atelier, The Vault, The Circle, Travel Atelier, Skin Architecture, academy and institutional training.

## Media
- `assets/media/` contains optimized editorial web media derived from the current project assets.
- `assets/video/` contains clean looped motion studies built from current high-resolution source media.
- `assets/masters8k/` contains 7680×4320 / 4320×7680 master derivatives for art-direction/export needs. These are 8K-dimension derivatives of the available source media, not native 8K camera captures.

## Important production notes
Product prices and course prices are reference/proposed values and should be verified before launch. Product inclusion does not imply authorization or endorsement by the named brands. Commercial launch requires backend/payment, inventory, authentication, protected video delivery, customer Look DNA storage and privacy controls.
